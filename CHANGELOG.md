# Changelog

## [0.2.5] - 2026-10-19

- Replaced the 8-conductor option with **7 conductors**: three side-arm pairs plus one centered top cable.
- Reused the 6-conductor edge-based tower geometry; the seventh cable attaches at the existing apex.
- Applied layout changes across all pylons and their cable spans.
- Provided an update path for scenes created with the previous 8-conductor mode.

## [0.2.4] - 2026-10-19

- Switched to explicit, readable layout buttons.
- Introduced an 8-conductor option, superseded by the 7-conductor preset in v0.2.5.

## [0.2.3] - 2026-10-19

- Made conductor layout a network-wide control.
- Regenerated spans when the network layout changes.

## [0.2.2] - 2026-10-19

- Fixed Blender 5.2 curve subdivision node construction.

## [0.2.1] - 2026-10-19

- Updated Geometry Nodes modifier input access for Blender 5.2.

## [0.2.0] - 2026-10-19

- Introduced Create Line and Add Pylon + Connect workflow using linked source meshes.

## [0.1.0] - 2026-10-19

- Initial pylon-anchor and live cable prototype.
